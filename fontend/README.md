# 锄大地计分小程序前端

## 项目结构

```
fontend/
├── pages/              # 页面
│   ├── index/         # 首页（选择模式）
│   ├── unified-score/ # 统一计分
│   ├── lan-room/      # 局域网房间
│   ├── online-room/   # 联网房间
│   ├── game/          # 游戏计分
│   └── round-results/ # 局数结果
├── store/             # Pinia 状态管理
├── utils/             # 工具函数
├── App.vue            # 应用入口
├── main.js            # 主文件
├── manifest.json      # 小程序配置
└── pages.json         # 页面配置
```

## 安装依赖

```bash
npm install
```

## 开发

使用 HBuilderX 或 uni-app CLI：

```bash
npm run dev:mp-weixin
```

## 构建

```bash
npm run build:mp-weixin
```

## 配置

1. 修改 `utils/request.js` 中的 `BASE_URL` 为实际的后端地址
2. 修改 `manifest.json` 中的 AppID（如果需要）
3. 在微信开发者工具中导入项目

## 功能说明

### 统一计分模式
- 单个用户输入所有玩家的牌数
- 每局结算后自动计算得分
- 可查看历史局数和累计得分

### 局域网计分模式
- 创建房间，生成房间号
- 局域网内其他玩家输入房间号加入
- 每个玩家输入自己的牌数
- 房主结算后计算得分

### 联网计分模式
- 创建房间，生成6位房间号
- 其他玩家输入房间号加入
- 每个玩家输入自己的牌数
- 房主结算后计算得分

## 得分计算规则

玩家1得分 = (玩家2-玩家1) + (玩家3-玩家1) + (玩家4-玩家1)
玩家2得分 = (玩家1-玩家2) + (玩家3-玩家2) + (玩家4-玩家2)
玩家3得分 = (玩家1-玩家3) + (玩家2-玩家3) + (玩家4-玩家3)
玩家4得分 = (玩家1-玩家4) + (玩家2-玩家4) + (玩家3-玩家4)
